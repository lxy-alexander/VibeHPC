= Bandwidth Documentation
:toc:

This document is the bandwidth evidence template for this submission tree. Fill
it with the submitted system's actual network topology and measured benchmark
throughput before final review. Do not copy bandwidth numbers from another
system unless the hardware and network topology are identical and documented in
the submitted system JSON.

== Required proof

For each submitted `system_desc_id`, document:

* network adapters, link speed, and topology
* whether traffic uses host memory, GPUDirect RDMA, or another approved path
* ingress bandwidth available to the SUT
* egress bandwidth available from the SUT when the benchmark has large outputs
* the largest measured throughput for each submitted benchmark and scenario

The proof should show:

----
required_bandwidth_bytes_per_sec <= available_bandwidth_bytes_per_sec
----

== Final check

The final submission must include completed bandwidth evidence for every
submitted system and benchmark. Each value must match the submitted
`systems/<system_desc_id>.json`, `user.conf`, and `mlperf_log_summary.txt`
files. Do not submit placeholder bandwidth values.
