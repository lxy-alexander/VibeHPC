# Submission Documentation

This directory is intentionally limited to documentation needed for an MLPerf
Inference submission review.

This submission is prepared by VibeHPC and is derived from NVIDIA MLPerf
Inference code.

Keep these files in the submitted tree:

- `calibration.adoc`: calibration and quantization process notes.
- `bandwidth.adoc`: bandwidth methodology and per-system proof template.
- `licenses_and_attributions.adoc`: legal notices and third-party attribution
  pointer.

Scenario-specific files such as `README.md`, `calibration_process.adoc`,
`measurements.json`, `mlperf.conf`, and `user.conf` are generated by the NVIDIA
submission flow and copied into `results/<system>/<benchmark>/<scenario>/`.

Do not remove copyright headers, third-party attribution notices, model license
files, or dataset license references from code, model artifacts, or submission
documentation.
